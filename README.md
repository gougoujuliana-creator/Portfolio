# Portfolio Personnel — Juliana GOUGOU

Portfolio professionnel développé en HTML5, CSS3 et JavaScript vanilla.

## Technologies utilisées

- **HTML5** — Structure sémantique
- **CSS3** — Design responsive avec variables CSS, Flexbox et Grid
- **JavaScript** — Interactivité vanilla sans framework

## Fonctionnalités

- Navigation responsive avec menu hamburger
- Mode clair / sombre avec sauvegarde localStorage
- Filtrage des projets par catégorie
- Animations au scroll
- Typewriter effect dans le hero
- Validation du formulaire de contact
- Bouton retour en haut
- Design entièrement responsive

## Installation

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/votre-username/portfolio-juliana.git
   ```

2. Ouvrir `index.html` dans un navigateur

## Personnalisation

- **Photo de profil** : Remplacer `images/profile.jpg`
- **CV** : Placer le fichier PDF dans `assets/cv/cv-juliana.pdf`
- **Liens sociaux** : Modifier les URLs dans `index.html` (section Contact et Footer)
- **Projets** : Modifier les cartes de projets directement dans `index.html`
